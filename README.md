# 七苦 · 长夜圣堂

魂系 boss 战原型（浏览器 / Three.js）：戴铁面具的女战士，对决 3 倍身高、背插七剑的七苦圣女。
模型来自 Tripo3D（P2 生成 + Mixamo 骨骼），概念图来自 Codex image，音乐与音效全部程序合成。

## 运行

需要 Node.js 20 以上。首次运行会自动安装 three.js。

```bash
./play.sh            # 启动本地服务器并打开浏览器（http://127.0.0.1:5173/）
```

第二个场景《火焰山 · 牛魔》：http://127.0.0.1:5173/niumo.html（WASD 移动，J 轻击，K 重击，L 格挡，I 芭蕉扇，空格翻滚）。设计文档见 `docs/niumo_*.md`。

跑测试前先装截图工具的依赖：`cd tools/render && npm install`，然后 `cd game && node test/smoke.mjs fullfight`、`node test/niumo_smoke.mjs`。

打开后先「点击开始」（浏览器要求点一次才能出声），随即播放约 50 秒的开场 MV（Enter / Esc / 手柄 Start 跳过）：烛火 → 圣堂 → 化作蜡像的跪拜骑士 → 刺在她背上的七剑 → 背对我们跪在玫瑰窗下祈祷的圣女 → 玫瑰窗暗下（「神从未回应。」）→ 月光中推门而入的女战士 → 标题「七苦」。MV 配有专门的合成配乐（独唱 → 合唱 → 管风琴 → 静默 → 心跳般的定音鼓 → 标题重音）。之后在标题菜单点「开始」，走近跪着的圣女会触发约 32 秒的起身过场（同样可跳过）；死亡后直接重来，不再播过场。

| 操作 | 键鼠 | 手柄 |
|---|---|---|
| 移动 / 视角 | WASD / 鼠标 | 左摇杆 / 右摇杆 |
| 轻攻击（三连） | 左键 | RB |
| 重攻击（按住蓄力） | Shift+左键 或 F | RT |
| 冲刺突刺（奔跑中攻击） | 按住 Shift 跑动时按左键 | 长按 B 跑动时按 RB / RT |

| 圣泪瓶（回血，4 瓶） | E | X |
| 暂停（含设置） / 跳过过场 | Esc / Enter | Start / Y |

## 内容

- 圣女：连段长短不定——横扫后可能接下劈、突刺后可能接横扫、二阶段下劈后还会再接横扫（一阶段最多接一招，二阶段最多两招，接招时收招动作会加速衔接）；招式包括延迟下劈（冲击波）、两段横扫、突刺冲锋、七剑齐射、跪地祈祷降下光柱（地面先亮起光圈，光柱是一束有亮边、中间半透明的光管，落在镜头旁也不会白屏）；刀剑类攻击在蓄力到顶的一瞬剑尖会亮起一颗金星（配一声清响），这就是出手的信号，延迟下劈会在金星之后再停顿一拍；削韧会单膝跪地硬直（期间受到的伤害提高）。外观是银白与金色的圣像（象牙银甲、金色饰边、带光晕与放射光芒的金色圣环、金属面具般的圣容）。半血时背对玩家跪下祈祷，光芒觉醒，展开光翼（二阶段：金色更浓，更快、更狠，新增光翼爆发——蓄力时地面会画出 7.3 米的金色危险圈并由内向外填满，填满即爆发；暖金色调但不过曝，轮廓始终清楚），音乐同时切换。击败后她面向你跪地祈祷，身体由内而外发光，七剑落下插在四周，晨光涌入，她燃成金光消散，最后才出现「祷告已终」。
- 冲刺突刺：奔跑中出手，女战士压低身体长距离突刺，把冲刺的势头带进圣女腿上，适合追上 3 倍身高、步幅巨大的她。
- 处决：圣女单膝跪地硬直时（弹反三次或重击削光韧性），在她身前按左键（或重攻击）处决：冲上前把剑刺入她胸口，大伤害、长顿帧、慢动作与金光爆发，全程无敌；每次跪地只能处决一次。
- 锁定与镜头：锁定后镜头后拉并收窄视角（55° → 45° 的长焦感），她在画面里显得更高大，相对女战士的屏幕高度比原来大约高 15–20%；镜头同时自动抬头，把 3 倍身高的圣女和你一起框进画面，准星落在她胸口；镜头只待在中殿里，不会退进黑暗的侧廊；离镜头太近的蜡烛和铁烛台会渐隐，不挡视线；贴着墙柱打、或在自由视角下她站在镜头后方时，镜头会自动拉近，不会被柱子、墙壁或她的长袍挡住视线，视线通畅后再缓缓退回。
- 格挡与弹反：刀剑攻击可格挡（掉少量血、扣大量体力，体力耗尽被破防）；被击中前约 0.18 秒内按下格挡即完美弹反，不受伤害并大幅削减圣女韧性。冲击波、光柱、光翼只能翻滚躲开。
- 打击感：命中顿帧、震屏与方向推力、FOV 冲击、金色火花与光点、刀光拖尾、受击闪白、色差、低血红边、手柄震动、伤害累计数字与血条残影；被击中的一方在顿帧里颤动、之后上身被打得后仰（圣女出招时有霸体，但每一刀依然看得出吃到了）。
- 暂停菜单：总音量、音乐、音效、视角灵敏度、镜头震动强度、反转 Y 轴，调整立即生效并保存在本机浏览器里；手柄按 Start 暂停。
- 画面：深蓝月光 + 烛火暖金、满地烛光倒映的水面、彩绘玫瑰窗光柱；角色材质重新判定金属（钢、银、金）、轮廓光、只照角色的主光、湿腿、燃烧溶解；过场景深与宽银幕黑边。

## 音乐与音效

- 全部是 Web Audio 程序合成：开场独唱圣歌、过场静默、一阶段 70 BPM 合唱与管风琴、二阶段加强版、圣女只剩四分之一血时的终章（女高音长音、管风琴重音、更密的鼓点，钟声敲响、光环爆亮；各阶段都踩着同一拍无缝衔接）、胜利与死亡，以及 29 种音效（格挡是钝响的金属撞击，弹反是悬在殿里的清亮长鸣，处决是一声闷雷加合唱回应）。
- 动态混音：血量低于 30% 时音乐像隔了一层（低通滤波，越残越闷），低于 25% 有心跳；弹反、处决等慢动作瞬间音乐也会短暂收拢。
- 试听：`game/test/audio_preview/*.wav`，或运行 `./play.sh` 后打开 `http://127.0.0.1:5173/test/audio_check.html`。
- 换成你自己的曲子：把 mp3 放到 `game/assets/audio/<状态>.mp3`（`hymn` / `tension` / `phase1` / `phase2` / `victory` / `defeat`），会自动替换对应的合成音乐。

## 目录

- `game/`：游戏本体（`index.html`、`src/`、`assets/`），模块与约定见 `game/ARCHITECTURE.md`
  - `src/arena.js` + `src/arena/`：教堂场景；`src/audio.js` + `src/audio/`：音乐与音效
  - `src/pose.js` + `src/moves.js`：程序化动作（IK 驱动）与全部招式；`src/look.js`：角色材质与光
- `concept/`：概念图；`prompts/`：对应提示词
- `tools/`：管线脚本（`gen_concepts.sh` Codex 出图、`rig_and_animate.sh` Tripo 绑骨与动作、`build_assets.sh` 模型优化入库、`render/render_glb.mjs` 模型多角度渲染、`contact_sheet.mjs` 拼图）
- `out/tripo/`：Tripo 原始输出；`review/`：检查图（`review/final_sheet.png` 是总览）

## 测试与调试

- 网址参数：`?skipintro` 跳过过场，`?god` 不死，`?debug` 暴露 `window.__game`，`?autostart` 跳过标题。
- 自动测试：`cd game && node test/smoke.mjs <start|intro|fight|combat|moves|strafe|phase2|victory|death|fullfight|block|critical|look|muffle|runattack|camwall|camsweep|settings|scale|bossmoves|volley|combo|pmoves|aistats|mv>`，截图在 `game/test/out/smoke/`。`fullfight` 用机器人从开场打到胜利；`look` 对比一、二阶段三个距离下的画面；`muffle` 检查低血时的音乐滤波；`camsweep` 让角色沿两侧墙走一圈，检查镜头从未被柱子挡住；`scale` 量出锁定视角下圣女与女战士在屏幕上的高度比；`bossmoves` 把每个招式定格在关键帧截图（`MOVES=slam,sweep,thrust,volley,pray` / `P2=1`）；`settings` 检查暂停菜单设置的生效与保存；`volley` 检查七剑齐射后没有剑悬在空中；`combo` 检查轻攻击三连的顺序；`pmoves` 把女战士的招式定格截图；`aistats` 统计圣女的出招分布与连段比例（`SECS=100`）；`mv` 播放开场 MV 并逐镜头截图，最后检查标题菜单出现（`MVT=` 自定义截图时间）。所有场景都会在场景模块加载失败（退回简易地面）或出现任何控制台错误/警告时判失败。
- 音频检查：`cd game && node test/audio_check.mjs`（离线渲染每个音效与曲目，测峰值、响度、时长，并输出 WAV 试听）。
